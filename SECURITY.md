# Security Policy

## Scope

This repository is a personal profile repository. It contains documentation only — no executable code, no software binary, no API endpoint.

There is no attack surface in the traditional sense.

## What belongs here

Reports relevant to this repository include:

- Impersonation of the author or misuse of his identity in connection with this profile
- Misrepresentation of the Collaborative Integrity Pact (CIP), its licensing or its status
- Inaccurate factual claims about the author's credentials, publications or professional standing

## What does not belong here

Reports concerning generative AI behaviour — sycophancy, hallucinatory recursive embedding, facade-alignment, faked CIP compliance under stress-test — belong to the research repository: see the [authentic-fluency security policy](https://github.com/meunier-jc/authentic-fluency/blob/main/SECURITY.md).
