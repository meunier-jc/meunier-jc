# Contributing to This Profile Repository

This repository is the GitHub profile of Jean-Christophe Meunier. It contains a bilingual profile README and repository-level Markdown rules. It is not the main venue for research contributions.

## Where to contribute

- Collaborative Integrity Pact (CIP), research, translations and documentation: contribute to [authentic-fluency](https://github.com/meunier-jc/authentic-fluency) — see its [contributing guide](https://github.com/meunier-jc/authentic-fluency/blob/main/CONTRIBUTING.md)
- Historical material (v1.x–v2.9): [Human-AI-Moral-Contract](https://github.com/meunier-jc/Human-AI-Moral-Contract) is an archive; only factual corrections are accepted there

## What is in scope here

Narrow, well-evidenced corrections to this profile:

- Factual errors in the README (dates, versions, links, credentials)
- Broken or outdated links
- Language improvements that do not alter meaning, kept consistent across the English and French sections

The profile README distinguishes direct evidence, author declarations, interpretations and hypotheses. Any correction that changes this distinction — especially regarding the author's own declarations — must include verifiable sources.

## How to submit

1. Open an issue describing the correction and its evidence, unless the change is a typo or a broken link.
2. Keep each pull request focused on a single purpose.
3. Use the commit-message conventions used across this account (see below).

Accepted commit format:

```text
<type>(<scope>): <imperative summary>
```

Accepted types: `docs`, `fix`, `chore`.
